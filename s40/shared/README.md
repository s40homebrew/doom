# Shared Doom target

One JAR for 6303 classic and C3-00. Build from the repository root with
`bash s40/build.sh shared`; install `s40/shared/dist/RM443AdaptiveDoom.jar`
and its matching JAD. Choose **Check firmware**, then **Start Doom**.
See the [main README](../../README.md) for WAD locations.

## Controls

| Action | C3-00 (QWERTY or QWERTZ) | 6303 classic |
| --- | --- | --- |
| Move / turn | D-pad | D-pad or 2/8/4/6 |
| Fire | Space or centre | 5 or centre |
| Use / open door | Enter | 0 |
| Strafe left / right | I / O | 1 / 3 |
| Run while held | K or Shift | 7 |
| Map | L | 9 |
| Next weapon | P | # |
| Open / close menu | Right softkey; Backspace opens | Right softkey or * |
| Menu select | Centre, Enter, Space or left softkey | Centre, 5 or left softkey |
| Back within menu | Backspace | Right softkey closes menu |

C3 also accepts WASD, Q/R for strafe, E for use, C for run, M for map,
N/B for next/previous weapon, and digits 1–8 to select a weapon.
Save names accept ASCII characters, Enter and Backspace.
