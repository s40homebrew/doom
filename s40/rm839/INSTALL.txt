Doom for Nokia 301 RM-839 firmware 02.33
Install RM839NativeDoom.jar with its matching JAD.
Put your IWAD in D:\doom\doom1.wad, then choose Start Doom.
D-pad or 2/4/6/8 moves; 5 fires; 0 uses; 1/3 strafes; 7 runs;
9 opens the map; # changes weapons; * or right softkey opens the menu.
No game data or sound is included. See the source README for other WAD paths.
